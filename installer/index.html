Preparing the installer…

This replaces your installed firmware and partition table. Back up first if you need a factory restore. Leaving erase unchecked preserves saved Handheld OS settings and history.

Once it starts

Wait for the Home screen. Press S for Settings, W to set up Wi-Fi, or A to set your carrier APN. Press Sym to return Home.

Press M for SMS. Cellular service requires an activated SIM, compatible LTE coverage and carrier approval. Carrier support varies.

Want AI chat? Paste your API key onto the device over USB, then press A on Home to chat over Wi-Fi.

Early test release. LoRa uses the Handheld OS protocol; Meshtastic is not included. Calls and Bluetooth pairing are still being tested. Read the release notes.

Device missing or installation stuck?
  • Try another USB data cable and a direct USB port.
  • Close serial monitors and other tabs connected to the device.
  • Hold BOOT, tap RST / RESET, release BOOT, then reconnect in the installer. Select the new Espressif USB / COM port if it changed.
  • After a successful install, tap RESET once if the Home screen does not appear.

macOS and Windows 10/11 normally support the built-in Espressif USB connection without an extra driver. Report a problem with your hardware revision, browser and error message. Keep phone numbers and SIM identifiers out of screenshots.
