Optional AI chat setup

Paste your key.
Chat on your deck.

Connect your T-Deck Pro, paste your API key, and save. This page sends settings directly to the device over USB.

Install the current Handheld OS release first and wait for its Home screen. Close other serial monitors and disconnect the installer tab.

Set up AI chat

Use desktop Chrome or Edge on macOS or Windows. Keep the USB data cable connected.

Connect your device to begin. Nothing is sent to an AI provider during setup.

Keep this for OpenAI, or enter your own OpenAI-compatible provider's HTTPS API base.

Use your provider's API key. An API account may have separate usage charges. This form replaces the saved key.

Your key goes only to the attached USB device. This page has no analytics, backend or external scripts and does not save the key in browser storage. The device stores the key in unencrypted NVS; keep the device and its flash backups private.

Then use the device

After saving, press A on the device's AI setup screen, then N to write a question. Enter sends it to your selected provider. Connect Wi-Fi first in Settings → W.

J/K pages through replies. Sym returns Home, where A opens AI chat again.

Setup does not test the key or make an API request. If your provider rejects it, check your account's API access and exact model name. More AI setup help.
